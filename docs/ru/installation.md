Pulsar работает на macOS 14 Sonoma и новее, на Mac с Apple silicon и Intel.

## Установка

1. Скачайте `Pulsar-<версия>.zip` из [последнего релиза](https://github.com/fosoaq/pulsar/releases/latest).
2. Распакуйте архив и перенесите `Pulsar.app` в «Программы».
3. Откройте Pulsar. Он появится в строке меню, а не в Dock.

## Если macOS не даёт открыть приложение

Pulsar не нотаризован Apple, поэтому при первом запуске macOS покажет предупреждение. Выберите одно из двух:

- откройте «Системные настройки» → «Конфиденциальность и безопасность», найдите сообщение о Pulsar и нажмите **«Всё равно открыть»**;
- или один раз выполните в Терминале:

```sh
xattr -dr com.apple.quarantine /Applications/Pulsar.app
```

## Первый запуск

- Pulsar попросит разрешение на уведомления. Разрешите, чтобы получать сообщения о неудачных и медленных тестах.
- macOS может спросить, разрешить ли Pulsar входящие подключения. Разрешите, иначе другие устройства не откроют веб-панель.
- При первом запуске из «Программ» Pulsar добавляет себя в объекты входа. Отключается в «Настройки → Общие».
- Если установлен Ookla Speedtest CLI, Pulsar использует его и сначала попросит принять лицензию Ookla; иначе начнёт со встроенного networkQuality. Подробнее — в разделе [Тесты скорости]({{ '/ru/speed-tests/' | relative_url }}).

## Обновления

Раз в сутки Pulsar проверяет, не вышла ли новая версия на GitHub. Если вышла, в меню появится ссылка: скачайте её и замените приложение в «Программах». Настройки и история сохранятся.

## Удаление

1. Завершите Pulsar из его меню.
2. Удалите `Pulsar.app` из «Программ».
3. Чтобы удалить ещё историю и настройки:

```sh
rm -rf ~/Library/Application\ Support/Pulsar
defaults delete io.github.fosoaq.Pulsar
```
