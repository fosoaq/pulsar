## Где лежат данные

| Что | Где |
|---|---|
| История тестов | `~/Library/Application Support/Pulsar/pulsar.sqlite` |
| Настройки | `~/Library/Preferences/io.github.fosoaq.Pulsar.plist` |

История — это база SQLite с одной таблицей `result`, её можно открыть любым инструментом для SQLite. По умолчанию Pulsar хранит историю год; «Настройки → Тесты → **Хранить историю**» меняют срок от 30 дней до «Всегда».

## Что уходит с Mac

- **Тесты скорости.** Каждый тест связывается с сервером замера. Ookla CLI ещё и отправляет результаты в Ookla, как это делает speedtest.net; networkQuality связывается с Apple.
- **Уведомления** уходят только в те каналы, которые вы настроили: Telegram, ntfy или ваш webhook.
- **Проверка обновлений.** Раз в сутки Pulsar спрашивает у GitHub, какая версия последняя. Ничего о вас и ваших результатах не отправляется.

В Pulsar нет аналитики и аккаунтов.

## В вашей сети

Веб-панель и API открыты для всех устройств в локальной сети и только читают данные, кроме запуска теста. Подробнее — в разделе [Веб-панель]({{ '/ru/dashboard/' | relative_url }}#access). Токен бота Telegram хранится в файле настроек Pulsar, который может прочитать только ваша учётная запись macOS.
