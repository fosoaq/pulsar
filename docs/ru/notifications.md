«Настройки → Уведомления» задают, когда Pulsar сообщает о проблемах:

- **Когда тест не прошёл**, например при пропавшем интернете.
- **Когда загрузка или отдача ниже** заданной скорости в Мбит/с. 0 отключает порог.

Уведомления всегда показываются в Центре уведомлений на Mac. Каждый канал ниже включается, как только заполнены его поля. Кнопка **«Отправить тестовое уведомление»** проверяет все каналы и показывает те, что не сработали.

## Telegram

1. Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте его токен.
2. Напишите боту любое сообщение, чтобы он мог вам отвечать.
3. Узнайте ID своего чата у [@userinfobot](https://t.me/userinfobot).
4. Вставьте токен и ID чата в настройки.

## ntfy

Укажите адрес темы, например `https://ntfy.sh/my-pulsar`, и подпишитесь на ту же тему в приложении [ntfy](https://ntfy.sh) на телефоне. Свой сервер ntfy тоже подойдёт. Тему на ntfy.sh может прочитать любой, кто знает её имя, поэтому выберите имя, которое трудно угадать.

## Webhook

После каждого теста Pulsar отправляет на адрес `POST` с JSON, а если сработало уведомление — ещё и поле `alert`. Подходит для Home Assistant, n8n и похожих инструментов.

| Поле | |
|---|---|
| `event` | `test.completed`, `test.failed` или `test.notification` для тестовой кнопки |
| `alert` | `title` и `body`, только если результат вызвал уведомление |
| `result` | Тест в том же виде, что в [HTTP API]({{ '/ru/api/' | relative_url }}); поля без значения пропускаются |

```json
{
  "event": "test.completed",
  "alert": { "title": "Медленное соединение", "body": "Загрузка 412 Мбит/с, ниже 800" },
  "result": {
    "id": 1042,
    "date": "2026-10-24T18:00:12Z",
    "engine": "ookla",
    "downloadMbps": 412.3,
    "uploadMbps": 458.1,
    "latencyMs": 3.6,
    "jitterMs": 0.4,
    "downloadLatencyMs": 14.2,
    "uploadLatencyMs": 19.8,
    "packetLossPercent": 0,
    "interfaceName": "en0",
    "server": "Example Fiber, Springfield",
    "isp": "Example ISP",
    "resultURL": "https://www.speedtest.net/result/c/…"
  }
}
```

Тексты `title` и `body` приходят на языке приложения. Ответ с кодом вне 200–299 считается ошибкой и показывается в настройках.
